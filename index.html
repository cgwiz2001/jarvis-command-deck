How this works

You only talk to Jarvis. With an xAI key, Jarvis answers instantly (spoken in Talk mode) and, when a job belongs to a specialist, adds it to Jarvis's inbox in Second Brain for that bot. Without a key, messages are simply added to the inbox. Jarvis's router checks the inbox 4× each weekday (00:00, 06:00, 12:00, 18:00 UK time) and hands each request to the right bot; it also happens straight away when you talk to Jarvis directly. This deck checks for updates every 45 seconds and fires a beam when a request is routed or answered.
