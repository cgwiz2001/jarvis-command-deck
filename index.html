How this works

You only talk to Jarvis. With an xAI key, Jarvis answers instantly (spoken in Talk mode) and, when a job belongs to a specialist, adds it to Jarvis's inbox in Second Brain for that bot. Without a key, messages are simply added to the inbox. If the instant routing webhook is set in Settings, the deck pings it so the job is handed to the right bot at once. Without that link, the request stays queued until you add it. This deck checks for updates every 45 seconds and fires a beam when a request is routed or answered.
